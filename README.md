# 게임 유저 VOC · 동향 대시보드

게임 커뮤니티의 게시글을 매주 수집해 제목을 AI(Claude)로 주제 · 감성 · 의견 유형별로 분류하고, 커뮤니티마다 평시 대비 크게 달라진 이슈를 찾아 본문까지 정독해 정리하는 주간 VOC 대시보드입니다. 매주 수요일 이번 주에 보고 · 대응할 이슈를 정하고 주간 보고로 옮기는 주간 점검 화면으로 만들었습니다. 지금은 로스트아크를 추적하고, 다음 게임은 아이온2입니다.

- 화면: https://hyunxn-01.github.io/game-voc-dashboard/
- 분석 절차 · 분류 모델 선정 · 정답 표 작성 방법 · 비용: 화면 왼쪽 메뉴의 '자료와 방법'

## 화면 구성

왼쪽 메뉴의 화면 일곱 개를 오가며 봅니다. 위의 선택 줄에서 게임 · 지역(국내 · 해외) · 기준 주를 고르고, 주소에 게임 · 지역 · 기준 주 · 메뉴 · 펼친 이슈가 담겨 같은 화면을 링크로 공유할 수 있습니다. AI(Claude)가 쓴 판단과 설명에는 'AI 초안' · 'AI 정독 요약'을 붙이고, 담당자가 확인한 판단은 '담당자'로 표시합니다.

| 메뉴 | 보는 것 |
|---|---|
| 판단할 것 | 이번 주 인사이트(이슈마다 주어와 핵심 숫자 한 줄), 숫자 다섯(글 수 · 부정 비율 · 이슈 후보 · PC방 점유율 · 스팀 동시 접속), 이번 주 판단할 것 표(판단 초안 · 변화 · 최근 13주 가운데 몇 주째 · 판단 이유 · 관련 공지, 행을 누르면 AI 정독 요약과 대표 글), 같은 주 운영 대응, 급상승 키워드, 근거 그래프, 지난 이슈 후보 |
| 동향 · 게임 지표 | 커뮤니티별 글 수 지수(평시 = 100), 같은 주 축의 PC방 점유율 · 순위와 스팀 동시 접속, 글 수와 신호(버그 · 이탈 · 복귀와 신규 표현)의 주별 · 일별 추이, 게시판별 글 수 |
| 운영 대응 | 공식 공지를 문제 안내 · 소통 · 제재 · 변경 예고로 나눈 최근 13주 목록(운영 보상 표시 포함)과 대응 전후 주의 부정 비율 |
| 주간 보고 한 쪽 | 수요일 보고에 옮길 한 쪽(결론 · 숫자 · 이슈 · 13주 추이 · 같은 주 운영 대응 · 비교 기준). 글로 복사와 A4 한 쪽 인쇄 |
| 감성 · 주제 | 커뮤니티별 순감성 지수, 감성 비율, 주제별 부정 비율, 주제별 불만 · 개선 요청, 주제 · 의견 유형, 키워드 그룹 비중과 추이, 급상승 키워드 |
| 업데이트 효과 | 업데이트 주의 글 수 · 주요 변화 · 부정 비율 |
| 자료와 방법 | 분석 절차(수집 · 분류 · 집계 · 본문 정독 · 판단 초안 · 공개), 분류 모델 정확도와 비용, 수집 현황, 수집 대상과 이용 규칙, 게임 지표 출처, 판정 기준, 한계와 해석 시 유의점 |

## 이 저장소에 있는 것

- `index.html`: 화면(파일 하나)
- `games.json`: 게임 목록
- `data/<게임>.json`: 화면 데이터(집계 값, 대표 글의 제목 · 링크, 본문에 실재하는 15어절 미만 인용, 정독 요약, 판단 초안, 게임 지표 숫자, 운영 대응 공지의 제목 · 링크). 제목과 인용은 원래 표현 그대로 싣습니다

게시글 목록 원자료 · 분류 결과 · 본문은 이 저장소에 없습니다. 수집 · 분류 · 집계는 개인 작업 공간에서 매주 실행하고, 결과 화면만 이 저장소에 게시합니다.

## 데이터 수집 방식

- 인벤 · 아카라이브 · 로스트아크 공식 홈페이지 게시판의 공개 게시글 목록을 수집합니다. 레딧 글은 레딧 글을 별도 보관해 제공하는 제3자 서비스(Arctic Shift)에서 수집합니다.
- 게임 지표는 더로그 PC방 주간 리포트(순위 · 점유율 · 사용시간 숫자와 리포트 링크만 싣고 표 그림은 싣지 않습니다)와 SteamCharts의 시간별 동시 접속 자료(Valve 공식 API로 크기를 대조)에서, 운영 대응은 로스트아크 공식 홈페이지 공지에서 가져옵니다.
- 사이트마다 robots.txt를 확인했고, 사이트별로 요청을 하나씩 순차 전송하며, 요청 주체(User-Agent)에 개인 비상업 연구용 주간 수집임을 밝힙니다.
- 작성자 정보는 수집하지 않습니다. 게시글의 저작권은 각 작성자와 커뮤니티에 있습니다. 게재되면 안 되는 글이 있으면 이 저장소의 Issues로 알려 주세요. 제외하겠습니다.
