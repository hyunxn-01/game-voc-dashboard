# 게임 VOC · 유저 동향 대시보드

게임 커뮤니티의 글을 매주 모아 제목을 AI(Claude)로 주제 · 감성 · 의견 유형으로 나누고, 평시보다 크게 늘어난 이슈는 본문까지 읽어 정리하는 주간 VOC 대시보드입니다. 지금은 로스트아크를 추적하고, 다음 게임은 아이온2입니다.

- 화면: https://hyunxn-01.github.io/game-voc-dashboard/
- 만든 과정 · 분류 모델 비교 · 정답 표를 만든 방법 · 비용: 화면의 ⑤ '어떻게 만들었나'

## 화면 구성

| 화면 | 보는 것 |
|---|---|
| ① 이번 주 요약 | 결론 표(얼마나 · 무엇을 · 어떤 글 · 왜 그때 · 얼마나 급한가 · 무엇을 할까)와 단계별 카드 |
| ② 동향 타임라인 | 커뮤니티 · 게시판별 주간 글 수, 주마다 올라온 이슈 후보와 본문 정독 요약, 업데이트 효과 |
| ③ 감성 추이 | 커뮤니티별 순감정, 감성 비율, 주제별 부정 비율 |
| ④ VOC 주제 지도 | 낱말 묶음 비중, 주제 · 의견 유형, 불만 · 개선 요청이 많은 주제 |
| ⑤ 어떻게 만들었나 | 수집 → 분류 → 집계 → 본문 정독 → 화면, 정확도와 비용, 기준치, 낱말 사전, 읽을 때 주의할 점 |

## 이 저장소에 있는 것

- `index.html`: 화면(파일 하나)
- `games.json`: 게임 목록
- `data/<게임>.json`: 화면 데이터(집계 값, 대표 글의 제목 · 링크, 본문에 실제로 있는 15어절 미만 인용, 정독 요약)

글 목록 원자료 · 분류 결과 · 본문은 이 저장소에 없습니다. 수집 · 분류 · 집계는 개인 작업 공간에서 매주 돌리고, 결과 화면만 이 저장소에 올립니다.

## 데이터를 받는 방식

- 인벤 · 아카라이브 · 로스트아크 공식 홈페이지 게시판의 공개 글 목록을 받습니다. 레딧 글은 레딧 글을 보관해 내주는 제3자 서비스(Arctic Shift)에서 받습니다.
- 사이트마다 robots.txt를 확인했고, 한 사이트에 한 번에 하나씩 요청하며, 요청 이름에 개인 비상업 연구용 주간 수집임을 밝힙니다.
- 작성자 정보는 모으지 않습니다. 글의 저작권은 각 작성자와 커뮤니티에 있습니다. 실리면 안 되는 글이 있으면 이 저장소의 Issues로 알려 주세요. 빼겠습니다.
