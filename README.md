# 게임 유저 VOC · 동향 대시보드

게임 커뮤니티의 게시글을 매주 수집해 제목을 AI(Claude)로 주제 · 감성 · 의견 유형별로 분류하고, 평시 대비 급증한 이슈는 본문까지 정독해 정리하는 주간 VOC 대시보드입니다. 지금은 로스트아크를 추적하고, 다음 게임은 아이온2입니다.

- 화면: https://hyunxn-01.github.io/game-voc-dashboard/
- 분석 절차 · 분류 모델 선정 · 정답 표 작성 방법 · 비용: 화면 맨 아래 '자료와 방법'

## 화면 구성

한 페이지에 구간 일곱 개가 위에서 아래로 놓이고, 화면 위에 고정되는 줄에서 게임 · 지역 · 기준 주를 고르고 구간으로 이동합니다. 주소에 게임 · 지역 · 기준 주 · 펼친 이슈 후보가 담겨 같은 화면을 링크로 공유할 수 있습니다.

| 구간 | 보는 것 |
|---|---|
| 이번 주 요약 | 최근 13주 레일(주마다 이슈 후보 수 · 큰 업데이트 · 연휴 주 · 판정하던 커뮤니티가 빠진 주, 누르면 그 주로 이동)과 주간 요약 표(글 수, 이슈 후보, 급상승 키워드, 대표 글, 같은 주 업데이트 · 이벤트, 중요도, 대응 메모) |
| 이슈 후보 | 기준 주의 이슈 후보 표(수치 · 평시 대비 · 최근 9주 추이 · 충족 기준 · 중요도). 행을 누르면 AI 정독 요약과 대표 글. 지난 이슈 후보 목록 |
| 동향 타임라인 | 글 수와 신호(버그 · 이탈 · 복귀와 신규 표현)의 주별 · 일별 추이, 커뮤니티별 · 게시판별 보기, 게시판별 글 수 |
| 감성 추이 | 커뮤니티별 순감성 지수, 감성 비율, 주제별 부정 비율 |
| VOC 주제 지도 | 주제별 불만 · 개선 요청, 주제 · 의견 유형, 키워드 그룹 비중과 추이, 급상승 키워드 |
| 업데이트 효과 | 업데이트 주의 글 수 · 주요 변화 · 부정 비율 |
| 자료와 방법 | 분석 절차(수집 · 분류 · 집계 · 본문 정독 · 공개), 분류 모델 정확도와 비용, 수집 현황, 판정 기준, 키워드 사전, 한계와 해석 시 유의점 |

## 이 저장소에 있는 것

- `index.html`: 화면(파일 하나)
- `games.json`: 게임 목록
- `data/<게임>.json`: 화면 데이터(집계 값, 대표 글의 제목 · 링크, 본문에 실재하는 15어절 미만 인용, 정독 요약). 제목과 인용의 욕설은 X로 가려 싣습니다

게시글 목록 원자료 · 분류 결과 · 본문은 이 저장소에 없습니다. 수집 · 분류 · 집계는 개인 작업 공간에서 매주 실행하고, 결과 화면만 이 저장소에 게시합니다.

## 데이터 수집 방식

- 인벤 · 아카라이브 · 로스트아크 공식 홈페이지 게시판의 공개 게시글 목록을 수집합니다. 레딧 글은 레딧 글을 별도 보관해 제공하는 제3자 서비스(Arctic Shift)에서 수집합니다.
- 사이트마다 robots.txt를 확인했고, 사이트별로 요청을 하나씩 순차 전송하며, 요청 주체(User-Agent)에 개인 비상업 연구용 주간 수집임을 밝힙니다.
- 작성자 정보는 수집하지 않습니다. 게시글의 저작권은 각 작성자와 커뮤니티에 있습니다. 게재되면 안 되는 글이 있으면 이 저장소의 Issues로 알려 주세요. 제외하겠습니다.
